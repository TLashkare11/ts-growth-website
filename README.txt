FREE HOSTING WITH GITHUB PAGES:
1. Create/sign in to a GitHub account.
2. Create a new public repository, e.g. ts-growth-website.
3. Upload index.html, style.css and script.js to the repository root.
4. Open repository Settings -> Pages.
5. Under Build and deployment choose Deploy from a branch; select main and /(root), then Save.
6. Wait for deployment. GitHub will show the public website URL in Settings -> Pages.

A custom .com/.in domain normally costs extra. Free hosting may have platform limits.
